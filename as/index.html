ছিংক সমস্যা নহয়, প্ৰথমে অনুমতিৰ সীমা স্পষ্ট কৰা.
ছজন মানুহ, এটা গ্ৰুপ, এটা আবেলি — এপেজ মাৰ্জনা কৰি উলিয়ালে.

🔊 প্ৰত্যেক সহায়কক বেলেগ মাত দিয়া, বাৰ্তা স্বয়ংক্ৰিয়ভাৱে বাজিব — তেওঁলোকে গ্ৰুপত কয়, তুমি নোচোৱাকৈও কোনে কৈছে জানিব পাৰিবা.

সুৰক্ষা

তোমাৰ ডেটা কেৱল তোমাৰ

Agent এ তোমাৰ কম্পিউটাৰ চলাব পাৰে, অৰ্থাৎ যিকোনো সময়ত তুমি তাৰ অনুমতি নিয়ন্ত্ৰণ কৰিব লাগে. প্ৰতিটো স্তৰে তোমাৰ হৈ বাধা দিয়ে, প্ৰতিটো সংবেদনশীল খোজত তোমাৰ সন্মতি লাগে.

🛡

দুিস্তৰীয় চেণ্ডবক্স

এপ স্তৰত PathGuard চাৰিস্তৰীয় প্ৰৱেশ নিয়ন্ত্ৰণ + অপাৰেটিং চিষ্টেম স্তৰৰ চেণ্ডবক্স (macOS Seatbelt / Linux Bubblewrap / Windows restricted token). Agent ৰ অনুমতি তোমাৰ হাতত.

🔒

লোকেল প্ৰথম

ডেটা তোমাৰ যন্ত্ৰত থাকে, ক্লাউডৰ ওপৰত নিৰ্ভৰ নকৰে. সম্পূৰ্ণ লোকেল চলাব পাৰা, গোপনীয়তাৰ কোনো ভয় নাই. তোমাৰ স্মৃতি, কথোপকথন, ফাইল — সকলো তোমাৰ হাতত.

✅

সংবেদনশীল কামৰ নিশ্চিতকৰণ

ফাইল লিখা, আদেশ চলোৱা, নেটৱৰ্ক অনুৰোধ — প্ৰতিটো খোজত তোমাৰ সন্মতি. সাধাৰণতে চিষ্টেম ফাইল কেৱল পঢ়ে, লিখা-মচা কাম ডিৰেক্টৰী আৰু নিয়ন্ত্ৰিত ডেটা ডিৰেক্টৰীত সীমাবদ্ধ.
