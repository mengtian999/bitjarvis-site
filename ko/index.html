그룹 협동

Jarvis와 한 팀 만들기

어시스턴트 하나 아니라 팀. 여러 Agent 생성, 각기 기억과 개성. 그룹에 넣으면 스스로 분담.

너는 지시를 내리고, Ta는 분해·실행. 다양한 역할의 Agent가 같은 그룹에서 협력, 팀·디바이스 넘나들 수 있어.

"한 개의 Ta"에서 시작, 서서히 "한 팀"으로.

보안

네 데이터는 너의 것

Agent가 네 PC를 조작할 수 있으므로, 언제나 권한을 쥐어야 해. 각 계층이 막아주고, 민감한 동작은 네 승인 대기.

🛡

이중 샌드박스

응용 계층 PathGuard 4단계 접근 제어 + OS 계층 샌드박스 (macOS Seatbelt / Linux Bubblewrap / Windows restricted token). Agent 권한은 네 손안에서.

🔒

로컬 우선

데이터는 네 기기 안에, 클라우드 비 의존. 완전 로컬 실행도 가능, 프라이버시 리스크 0. 기억, 대화, 파일 모두 네 손안에서.

✅

민감 동작 승인

파일 쓰기, 명령 실행, 네트워크 요청, 단계마다 네 OK. 평소 시스템 파일은 읽기 전용, 쓰기·삭제는 워크스페이스와 관리 폴더로 제한.

📖

완전 오픈소스

데스크톱 Apache 2.0, 모바일 GPL v3, IM AGPL 3.0. 코드 감사 가능, 커뮤니티 감시 가능. 걱정되면 스스로 모든 줄 읽어봐.
