安全

你的数据，只属于你

Agent 能操作你的电脑，意味着你需要在任何时候掌控Ta的权限。每一层都替你挡着，每一步敏感操作都要你点头。

🛡

双层沙盒

应用层 PathGuard 四级访问控制 + 操作系统级沙盒（macOS Seatbelt / Linux Bubblewrap / Windows restricted token）。Agent 的权限在你的掌控之中。

🔒

本地优先

数据存在你本机，不依赖云。可以选择纯本地运行，无惧任何隐私风险。你的记忆、你的对话、你的文件，都在你手里。

✅

敏感操作确认

写文件、执行命令、网络请求，每一步都要你点头。平时只读访问系统文件，写入和删除限制在工作目录与受控数据目录。

📖

完全开源

桌面端 Apache 2.0，移动端 GPL v3，IM AGPL 3.0。代码可审计，社区可监督。你不放心可以自己看每一行代码。
