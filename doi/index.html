तुसें हुक्म दिंदे ओ, ओह् बांड कै लागू करदे न। बगैर भूमिका दे Agent इक्को ग्रुप च सहयोग करदे न, टीम ते उपकरणें दे बीच बी हस्तांतरण करदे न।

"इक Ta" थमां शुरू करो, होली-होली "इक टीम" बण जाग।

सुरक्षा

तुंदा डेटा सिर्फ तुंदा

Agent तुंदा कंप्यूटर चला सकदा ऐ, मतलब कदे बी तुंदे गी ओह्दी इजाजत काबू च रखनी पैंदी ऐ। हर परत तुंदे वल्लों रोकदी ऐ, हर नाजुक कदम पर तुंदी मंजूरी चाहिदी ऐ।

🛡

दो-परत सैंडबॉक्स

ऐप परत च PathGuard चार-परत पहुंच कंट्रोल + ऑपरेटिंग सिस्टम परत दा सैंडबॉक्स (macOS Seatbelt / Linux Bubblewrap / Windows restricted token)। Agent दी इजाजत तुंदे हत्थ च।

🔒

लोकल पैह्लें

डेटा तुंदे यंत्र च, क्लाउड पर निर्भर नीं। पूरा लोकल चलाई सकदे ओ, गोपनीयता दा कोई डर नीं। तुंदी याद, गल्लबात, फाइलां — सब तुंदे हत्थ च।

✅

नाजुक कमें दी पुष्टि

फाइल लिखना, हुक्म चलाना, नेटवर्क बिनती — हर कदम पर तुंदी मंजूरी। आम तौर पर सिस्टम फाइलां सिर्फ पढ़दा, लिखना-मेटना कम डायरेक्टरी ते काबू आली डेटा डायरेक्टरी तगर सीमित।
