നിങ്ങൾ കമ്പ്യൂട്ടറിൽ ജോലി ചെയ്യുന്നു, പെട്ടെന്ന് പുറത്തുപോകണം. ഫോണിൽ ഒരു കമാൻഡ് കൊടുക്കൂ, ജോലി അങ്ങോട്ട് അയക്കൂ — Ta ഓടിക്കൊണ്ടിരിക്കും, നിങ്ങൾ എപ്പോഴും നോക്കൂ, മാറ്റൂ.

വീട്ടിൽ തിരിച്ചെത്താൻ കാത്തിരിക്കരുത്. ഫോണിൽ കമാൻഡ് കൊടുക്കൂ, ഡെസ്ക്ടോപ്പിലെ Agent നിങ്ങളുടെ കൈയിലേക്ക് വരും.

Ta കമ്പ്യൂട്ടറിൽ പാതി എഴുതിയ റിപ്പോർട്ട്, പാതി തിരഞ്ഞ ഡാറ്റ, ഓടുന്ന ജോലി — ഉള്ളതുപോലെ തുടരുന്നു.

നിങ്ങൾ ഉത്തരവ് കൊടുക്കൂ, അവർ പങ്കിട്ട് നടപ്പാക്കും. വ്യത്യസ്ത റോളുകളിലെ Agent ഒരേ ഗ്രൂപ്പിൽ സഹകരിക്കും, ടീമുകൾക്കും ഉപകരണങ്ങൾക്കുമിടയിലും റിലേ ചെയ്യും.

"ഒരു Ta"-യിൽ തുടങ്ങൂ, പതിയെ "ഒരു ടീം" ആകും.

സുരക്ഷ

നിങ്ങളുടെ ഡാറ്റ നിങ്ങളുടേത് മാത്രം

Agent നിങ്ങളുടെ കമ്പ്യൂട്ടർ ഓടിക്കാം, അതായത് എപ്പോഴും അതിന്റെ അനുമതി നിങ്ങളുടെ കൈയിൽ വേണം. ഓരോ പാളിയും നിങ്ങൾക്കുവേണ്ടി തടയുന്നു, ഓരോ സൂക്ഷ്മ നടപടിക്കും നിങ്ങളുടെ സമ്മതം വേണം.

🛡

ഇരു-പാളി സാൻഡ്ബോക്സ്

ആപ്പ് പാളിയിൽ PathGuard നാല്-പാളി ആക്സസ് കൺട്രോൾ + ഓപ്പറേറ്റിംഗ് സിസ്റ്റം പാളിയിലെ സാൻഡ്ബോക്സ് (macOS Seatbelt / Linux Bubblewrap / Windows restricted token). Agent-ന്റെ അനുമതി നിങ്ങളുടെ കൈയിൽ.

🔒

ലോക്കൽ ആദ്യം

ഡാറ്റ നിങ്ങളുടെ മെഷീനിൽ, ക്ലൗഡിനെ ആശ്രയിക്കുന്നില്ല. പൂർണ്ണ ലോക്കൽ ഓടിക്കാം, സ്വകാര്യതയ്ക്ക് ഭയമില്ല. നിങ്ങളുടെ ഓർമ്മ, സംഭാഷണം, ഫയലുകൾ — എല്ലാം നിങ്ങളുടെ കൈയിൽ.

✅

സൂക്ഷ്മ നടപടികളുടെ സ്ഥിരീകരണം

ഫയൽ എഴുതൽ, കമാൻഡ് ഓടിക്കൽ, നെറ്റ്വർക്ക് അഭ്യർത്ഥന — ഓരോ ചുവട്ടിനും നിങ്ങളുടെ സമ്മതം. സാധാരണയായി സിസ്റ്റം ഫയലുകൾ വായിക്കുന്നു മാത്രം, എഴുത്തും മായ്ക്കലും ജോലി ഡയറക്ടറിയിലും നിയന്ത്രിത ഡാറ്റ ഡയറക്ടറിയിലും മാത്രം.
