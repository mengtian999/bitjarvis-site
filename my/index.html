ချက်ထဲမှာ တစ်ခွန်းပြောလိုက်တာနဲ့ Ta က မှတ်ထားတယ်၊ မနက်ဖြန် ဒက်စ်တော့ပေါ်မှာ တွေ့မယ်
မနက်ဖြန် အစီအစဉ်ဖိုင်ရဲ့ လေသံကို နူးညံ့အောင် ပြင်ပေးပါ
ပြင်ပြီးပါပြီ၊ ကြည့်ပေးပါ၊ ထပ်ပြင်ချင်တာ ရှိလား။
မပြင်တာတွေကို အရင် သိမ်းထားမယ်၊ မနက်ဖြန် သင် လာတဲ့အခါ တိုက်ရိုက် ယူနိုင်တယ်။

စက်ပစ္စည်းအကြား ဆက်လုပ်မှု

လူ အိမ်ပြင်ထွက်သွားလည်း အလုပ် မပြတ်ဘူး

သင် ကွန်ပျူတာနဲ့ အလုပ်လုပ်နေတုန်း ရုတ်တရက် အပြင်ထွက်ရတယ်။ ဖုန်းကနေ အမိန့်တစ်ခု ပို့လိုက်ရင် အလုပ်ကို လွှဲပေးလိုက်ပြီး Ta က ဆက်လည်ပတ်တယ်၊ သင် အချိန်မရွေး ကြည့်နိုင်၊ ပြင်နိုင်တယ်။

အိမ်ပြန်ရောက်မှ ဆက်လုပ်ဖို့ မလိုဘူး။ ဖုန်းကနေ အမိန့်တစ်ခု ပို့လိုက်ရင် ဒက်စ်တော့ပေါ်က Agent က သင့်လက်ထဲ ရောက်လာတယ်။

Ta က ကွန်ပျူတာပေါ်မှာ တစ်ဝက်ရေးနေတဲ့ အစီရင်ခံစာ၊ တစ်ဝက်ရှာနေတဲ့ ဒေတာ၊ တစ်ဝက်လည်ပတ်နေတဲ့ တာဝန်—အားလုံးကို မပြောင်းမလဲ ဆက်လုပ်တယ်။

အုပ်စုဖွဲ့ ပူးပေါင်းမှု

Jarvis ရှိရင် သင် အဖွဲ့တစ်ဖွဲ့လည်း ဖွဲ့နိုင်တယ်

အလုပ်လုပ်နေတာ လက်ထောက်တစ်ယောက် မဟုတ်ဘူး၊ တစ်အုပ်စုလုံး။ Agent များစွာ ဖန်တီးပြီး တစ်ခုစီမှာ သီးခြားမှတ်ဉာဏ်နဲ့ ကိုယ်ပိုင်စရိုက် ထားနိုင်တယ်။ အုပ်စုတစ်ခု ဖွဲ့လိုက်ရင် Ta တွေ ကိုယ်တိုင် အလုပ်ခွဲကြတယ်။

သင် အမိန့်ပေးဖို့ တာဝန်ယူ၊ Ta တွေ ခွဲခြမ်းစိတ်ဖြာပြီး အကောင်အထည်ဖော်ဖို့ တာဝန်ယူ။ မတူညီတဲ့ အခန်းကဏ္ဍက Agent တွေ အုပ်စုတစ်ခုတည်းမှာ ပူးပေါင်းလုပ်ဆောင်နိုင်တယ်၊ အဖွဲ့အကြား၊ စက်ပစ္စည်းအကြားလည်း ဆက်လုပ်နိုင်တယ်။

"Ta တစ်ယောက်" ကနေ စပြီး တဖြည်းဖြည်း "အဖွဲ့တစ်ဖွဲ့" အဖြစ် ကြီးထွားလာတယ်။

🔊 လက်ထောက်တစ်ယောက်စီအတွက် မတူညီတဲ့ အသံ သတ်မှတ်ပေးထားတယ်၊ မက်ဆေ့ချ်တွေ အလိုအလျောက် ဖွင့်ပြီး Ta တွေ အုပ်စုထဲ စကားပြောနေတဲ့အခါ သင် ကြည့်စရာတောင် မလိုဘူး၊ နားထောင်လိုက်ရင် ဘယ်သူ ပြောနေတာလဲ သိရတယ်။

လုံခြုံရေး

သင့်ဒေတာ၊ သင့်ဆီပဲ

Agent က သင့်ကွန်ပျူတာကို လုပ်ဆောင်နိုင်တယ်ဆိုတာ ဘယ်အချိန်မဆို Ta ရဲ့ ခွင့်ပြုချက်ကို သင် ထိန်းချုပ်နိုင်ရမယ်။ အလွှာတိုင်းက သင့်အတွက် ကာကွယ်ပေးတယ်၊ အထိခိုက်မခံတဲ့ လုပ်ဆောင်မှုတိုင်းမှာ သင့်ခွင့်ပြုချက် လိုတယ်။

🛡

နှစ်လွှာ Sandbox

App အလွှာ PathGuard အဆင့်လေးဆင့် ဝင်ရောက်ခွင့် ထိန်းချုပ်မှု + လည်ပတ်စနစ်အလွှာ sandbox (macOS Seatbelt / Linux Bubblewrap / Windows restricted token)။ Agent ရဲ့ ခွင့်ပြုချက်တွေက သင့်ထိန်းချုပ်မှုအောက်မှာ။

🔒

မူလစက်ကို ဦးစားပေး

ဒေတာတွေက သင့်စက်ထဲမှာ သိမ်းထားတယ်၊ cloud ကို မမှီခိုဘူး။ လုံးဝ local ဖြင့် လည်ပတ်ဖို့ ရွေးနိုင်တယ်၊ မည်သည့် ကိုယ်ရေးလုံခြုံမှု အန္တရာယ်ကိုမှ မကြောက်ရဘူး။ သင့်မှတ်ဉာဏ်၊ သင့်စကားဝိုင်း၊ သင့်ဖိုင်တွေ အားလုံး သင့်လက်ထဲမှာ။

✅

အထိခိုက်မခံ လုပ်ဆောင်မှု အတည်ပြုချက်

ဖိုင်ရေးခြင်း၊ command လုပ်ဆောင်ခြင်း၊ ကွန်ရက်တောင်းခံခြင်း—အဆင့်တိုင်းမှာ သင့်ခွင့်ပြုချက် လိုတယ်။ ပုံမှန်အားဖြင့် စနစ်ဖိုင်တွေကို ဖတ်ရုံသာ ဝင်ရောက်နိုင်ပြီး ရေးခြင်း၊ ဖျက်ခြင်းကို အလုပ်လမ်းညွှန်နဲ့ ထိန်းချုပ်ထားတဲ့ ဒေတာလမ်းညွှန်အတွင်းသာ ကန့်သတ်ထားတယ်။

📖

လုံးဝ open source

ဒက်စ်တော့ Apache 2.0၊ မိုဘိုင်း GPL v3၊ IM AGPL 3.0။ ကုဒ်ကို စစ်ဆေးနိုင်တယ်၊ community က ကြီးကြပ်နိုင်တယ်။ စိတ်မချရင် သင် ကိုယ်တိုင် ကုဒ်တစ်ကြောင်းချင်းစီ ကြည့်နိုင်တယ်။
