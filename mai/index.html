अहाँक डेटा सिर्फ अहाँक

Agent अहाँक कम्प्युटर चला सकैत अछि, माने कखनोहुँ अहाँकेँ ओकर अनुमति काबूमे राखबाक पड़त। हर परत अहाँक तरफसँ रोकैत अछि, हर संवेदनशील कदम पर अहाँक मन्जूरी चाही।

🛡

दू-परत सैंडबक्स

एप परतमे PathGuard चारि-परत एक्सेस कन्ट्रोल + अपरेटिंग सिस्टम परतक सैंडबक्स (macOS Seatbelt / Linux Bubblewrap / Windows restricted token)। Agent क अनुमति अहाँक हाथमे।

🔒

लोकल पहिने

✅

संवेदनशील काजक पुष्टि

फाइल लिखब, कमाण्ड चलाब, नेटवर्क अनुरोध — हर कदम पर अहाँक मन्जूरी। सामान्य रूपसँ सिस्टम फाइल सिर्फ पढ़ैत अछि, लिखब-मेटब काज डाइरेक्टरी आ नियन्त्रित डेटा डाइरेक्टरी धरि सीमित।
